# 乳鸽游戏中心

从小米 MIX 4 上由 DeepCode 开发的游戏中心迁出的独立源码项目。应用用 Android WebView 加载本地网页，当前共有十九款在架游戏，包括益智、认字、动作、重力、声音与摄像头玩法，游戏资源离线打包；专业语音评分需联网。

当前 Android 包名为 `com.dsh.gamecenter`，版本为 **4.31 / versionCode 54**，以 [manifest](app/AndroidManifest.xml) 为准。网页游戏在 Mac 开发与测试，统一构建 APK 后安装到手机验证。

## 项目目录

| 目录 | 用途 |
|---|---|
| `app/assets/` | 当前菜单、十九款在架游戏和离线素材源码；另保留已暂停的小熊点心店原型 |
| `app/src/`、`app/res/`、`app/AndroidManifest.xml` | 原生外壳、图标、资源及权限声明 |
| `scripts/` | 固定 SDK 安装、APK 构建和开发版 WebView 检查脚本 |
| `tests/` | 直接执行真实页面脚本的 Node 回归测试 |
| `reference/phone-v4.1/`、`reference/phone-v4.1.apk` | 手机原版 4.1 / 24 的源码与 APK 快照，用于比较和回溯 |
| `reference/phone-skills/` | 手机 skill 审查快照，签名示例与历史设备地址已脱敏 |
| `docs/` | 构建、协作、审查及验收记录 |
| `.local-tools/`、`out/` | 本地 SDK 和构建产物，均不纳入 Git |

开发修改 `app/`。`reference/` 保留迁移快照，不能把它当作最新源码或构建输入。第三方字形数据的来源和许可见 [许可说明](THIRD_PARTY_NOTICES.md)。GitHub 仓库：[Jady891213/ruge-game-center-mobile](https://github.com/Jady891213/ruge-game-center-mobile)。Mac 维护 `main`，手机 DeepCode 使用 `deepcode-dev`。

逐项审查、截图和本轮修改见 [游戏中心审查](docs/Review%20Game%20Center/game-center-review.md)。

## K国王回家与专业读音（4.31）

新增 **K国王回家**：横屏20关，覆盖孩子指定的9个英语词。先拼写、再朗读，真实专业评分通过后施法救伙伴；每关5颗心，网络、没听清或服务异常不扣心。先给完整拼写提示，后续逐渐隐藏，支持大字母块和实体键盘。

开口读拼音已接通腾讯专业评测：整字按指定读音检查真实声调；拼读分别评声母/韵母/合读，再用末字音频独立检查声调。缺少有效声调时明确重试，不能只凭识别出目标字或高分算通过。

首页新增齿轮设置，集中音效、震动、常亮与网络服务。MiniMax可刷新真实5小时/本周剩余百分比及重置时间；腾讯余量暂未接入自动查询，提供官方控制台入口。

中英文示范使用MiniMax生成后离线打包，中文含80种指定读法和12条完整拼读，英语9词。播放示范、开始录音、后台和返回共用取消规则；API密钥不进入APK或Git。角色、词图、背景先用GPT生成原型和素材，再接入实际UI。

详见[4.31设计与验收](docs/Design%20K%20Kingdom%20and%20Speech%204.31/review.md)。合成标准音测试用于验证接口与规则，儿童口音和家庭噪声效果仍需试玩。

## 连续色盘与开口读拼音（4.30）

小小调色师使用GPT生成原型与角色素材，换成放大的连续色盘，目标星/当前圆点/轨迹与亮度对照保留，原颜料混色和过关逻辑保持。

看字打拼音新增“开口读拼音”入口：原60字朗读、12字入门拼读，含“b → ān → 班”。界面与腾讯云专业评测接入代码已准备；用户尚未开通服务，本版明确显示待家长配置，禁用收音，不显示模拟分数。服务接通后采用真实总分、片段分与声调结果，达标才下一题，语音记录独立于打字。详情见[调色与语音记录](docs/Design%20Paint%20and%20Reading%204.30/review.md)。

## 哼哼小飞机（4.29）

“唱跳小兔”入口改为 **哼哼小飞机**，固定横屏的无限飞行。高音持续升高、低音持续降低，中音/停声保持高度；实际位置平滑跟随，不需要每叫一次才动一格。首次舒适哼约0.85秒校准，之后新一轮/继续复用音域。宽云门、星星、三颗心与短护盾，难度缓慢增加并封顶；按住上下大按钮可辅助。

小飞机、云帽/星星与天空使用GPT生成素材，按实际透明主体裁切并保持比例。新最高门数独立记录，旧唱跳关卡与跑酷存档保留；旧实现仅用于历史回归，没有儿童入口。玩法参考、素材及验证见[飞行记录](docs/Design%20Pitch%20Flight%204.29/review.md)。

## 口袋探宝震感（4.28）

开锁拨动有独立六度刻度；探测信号按角度距离分七档，靠近时更密、更长、更强，转动经过目标也有强反馈，不再等停稳才明显。中心与可通关边缘有差别，成功提示留出450ms避免下一关覆盖。空间寻宝同时按方向和俯仰判断远近；关卡、三秒停稳规则、全局震动开关及原生时长/限频保持。真机输出和验证边界见[震感记录](docs/Design%20Radar%20Haptics%204.28/review.md)。

## 口令角色朝向（4.27）

口令小冒险使用四朝向各四帧的生成角色图集：向上看背面、向下看正面、左右有独立侧面；前进沿面朝方向，后退不转身，原地转向即时换姿态。站立、行走、跳跃、拿物品与暂停都保留朝向，原18关、口令词表和存档格式保持。素材与验收见[四向角色记录](docs/Design%20Voice%20Facing%204.27/review.md)。

## 汉字小书架（4.26）

首页「认字」新增 **识字库**，看字打拼音菜单也可进入。与原练习共用6组60字，按字、繁体或无声调拼音搜索；每字有简短释义、字源故事、可核古字形选例及资料出处。正文和图片离线打包，点击出处才在系统浏览器打开网页。

古字形为公开资料的摹本，不是AI绘制或现代篆体替代；只展示已查证的阶段，不为后起字补造甲骨文。不同读音、简化合并、相关古字和有争议的解释单独说明。繁体今字与今字使用现代字体，不能视为出土字形。字库不把练习分数当作逐字掌握记录，不读写现有游戏进度。

资料、图片许可和验收见[汉字小书架记录](docs/Design%20Hanzi%20Library%204.26/review.md)。

## 试玩反馈调整（4.25）

- 水果天平：前两关教学，第3关起用多条比例换算，库存不提供可直接照抄的答案；旧星数和解锁保留。
- 帽子小捣蛋：修正玩具比例/裁切，增加独立18关翻牌配对，原帽子关卡与新翻牌进度分开。
- 唱跳小兔：替换怪兽与标题，12帧小兔按高音跳、低音蹲；18关外新增渐难无尽挑战。
- 口令小冒险：更多同义短语、相对前后和转向、开门/喂兔/送回家；四向标识和可滚动口令表。仍是离线关键词识别，不是自由对话。
- 口袋探宝：360°保险箱与方向＋俯仰寻宝两个无尽计时模式；连续停稳3秒、过关加时、独立最高记录。使用相对姿态而非磁北，不需现实走路。原固定关卡/双人记录保留。
- 颜色小侦探：实时取样/目标对照和80分合格线；小小调色师：实际混色地图、目标/当前位置、调色轨迹及亮暗刻度。
- 钢珠迷宫：绿色水平进度条与2→1倒计时同步，过斜/后台及时清零。

完整规则、生成素材、声音对照与验收见[4.25记录](docs/Design%20Playful%20Refinement%204.25/review.md)。不新增联网或第三方运行库，仍共用原生音频/反馈/重力服务。

## 水果天平与声音冒险重做（4.24）

- **水果天平**：替换动物，6种水果的游戏质量固定、显示体型递增；点放或拖入即落下回弹，秤杆根据真实质量差以惯性/阻尼摆动，秤盘保持水平。18关重审，后6关为共享库存双秤，旧星数/解锁保留，旧规则草稿安全迁移。
- **怪兽变声冒险**：生成森林场景/道具和12帧角色动画，显示实时声量与高低音；修复首次加载的Canvas绘图异常。校准完成前场景停住，下一关默认声音，保留音域；可先在安全场景“试声音”。
- **口令小冒险**：生成森林地图、树墙和道具，逐格行走、跨水、举物、开门/喂兔/归巢与庆祝动画。默认语音开局，下一关复用采集会话，辅助方向盘可收起；漏听不惩罚，不要求每关选择输入模式。

原型、提示词与验收记录见 [4.24设计与验收](docs/Design%20Playful%20Polish%204.24/review.md)。声音继续使用一份共享原生采集/识别服务；录音不落盘，前台权限与暂停行为不变。真实设备合成声链路证明输入有效，儿童发音和现场噪声仍需试玩反馈。

## 钢珠迷宫放平即玩（4.20）

钢珠迷宫现有24关，保留原18关布局与存档。修正第13关机关安全判定：只检查挡板真正扫过的区域，球在安全侧即可直接点橙色挡板或转轴旋转，不再进入额外调整模式。新增19～24关，每关均有完整解法，并以真实物理回放验证收齐星星、到达终点。

## 旋转机关与数字碰碰（4.19）

钢珠迷宫保留原12关，新增第13～18机关关，第一次进入就能选第13关。点击大挡板图标进入调整状态，球暂时停住；点转轴旋转90度，再继续滚球。后两关需要先转向收星，再换向去终点；球在扫掠区域时禁止转动，不把球挤进墙。支持本关重置和机关朝向保存，旧关卡/存档兼容。

数字碰碰新增12个固定关卡：倾斜四向让数字积木滑动，相撞即相加（每块每步最多合并一次，结果最大10）。恰好等于星格数字就停住锁定，完成全部星格即可通关，多余积木可留下。前段学习小数相加，后段需要选方向、避开错合，并完成两个小目标；没有随机补数字、倒计时或无限翻倍。支持撤回、重置、选关、自动校准与后台明确继续。

三款重力游戏共用倾斜适配，两个格子游戏共用四向门限，音效震动共用；数字使用代码大字，选关插画由GPT生成。原型和提示词见 [机关与数字设计](docs/Design%20Gravity%20Mechanisms/art-prompts.json)。

## 重力玩具（4.18）

- **钢珠迷宫**重构为12个固定关卡：宽通道收星，逐步加入钥匙门和少量洞口；连续倾斜加速度、惯性、反向刹车和轻碰撞，掉洞回安全点并保留收集，没有生命/倒计时压力。

### 共享依赖的边界

整个应用只有一套 Android Java/WebView 外壳，游戏用本地 HTML/CSS/JavaScript、Canvas/SVG，无 npm 运行时依赖或远程 CDN。Node 是测试工具，Python/JDK/Android SDK 是构建工具。通用倾斜、反馈和原生服务从 shared/桥接共用；每款保留自己的玩法和布局。历史汉字几何仍有整理后的数据副本，基础CSS也未全部抽取，不能理解为所有源码和素材都已经唯一化。

## 字里找字答案库补漏（4.17）

答案采用离线“完整笔画选集 → 汉字”规则表，经人工审校；字形数据提供笔画，不会自动提供所有可拆出的汉字，也没有实时联网查字典。4.17复核60关，新增14个关内答案与28种合法选法，合计358个关内答案、673种合法选法，单关最多12字。

“田”的中横/中竖/底横可找出“土”，“思”“男”里同一部件同步支持；补充去→云、里→甲/旦、早→旦、星→早/旦等。相同字形及部件通过 answer-catalog.js 统一复用，避免独立早字关和日十组合关答案不同。已有合法选法和存档保持，新增答案由玩家收集，原解锁不回退。

查看 [完整答案清单](docs/Review%20Hanzi%20Answer%20Coverage/answer-inventory.md) 与 [验收记录](docs/Review%20Hanzi%20Answer%20Coverage/answer-coverage-review.md)。维护时运行 `node scripts/audit-hanzi-answers.mjs`，枚举选集检查查表一致、无歧义和数量上限；该校验不代表已经穷尽所有汉字。

## Mac 构建与测试

需要 Python 3.9+、JDK、Node.js 20+。测试只用 Node 内置模块，不需要安装 npm 依赖。Android 工具固定为 Build Tools 35.0.0 和 Android 35 平台 revision 2。

```bash
npm test
python3 scripts/setup-sdk.py --plan
python3 scripts/setup-sdk.py
python3 scripts/build.py --dev
python3 scripts/build.py
```

公开仓库不包含签名密钥；首次克隆需要自备签名材料并通过参数指定。覆盖更新已有应用必须使用原签名，由 Mac 发布端保管。已有 SDK 时可跳过安装步骤。本机已验证 JDK 18.0.2.1；JDK、SDK 和签名路径都可以通过构建参数或环境变量覆盖，详见 [构建说明](docs/build.md)。脚本只构建与校验，不会安装到手机。

产物为 `out/game-center-v4.23-dev.apk` 和 `out/game-center-v4.23.apk`，同名 JSON 记录版本、资源校验值与签名验证结果。正式版使用 APK 内 assets；开发版开启 WebView CDP，并可读取 `/sdcard/Android/data/com.dsh.gamecenter/files/dev/` 下的开发页面。

普通切后台会保留游戏状态并发送暂停/恢复事件；开发页面只有资源变化时才于回前台刷新。明确刷新开发页会重置页面状态。正式版关闭调试和外部开发页面能力。

## 连接与覆盖安装

ADB 已保存在工作区工具目录 `../../03-Android工具/platform-tools/adb`，也可使用 PATH 中安装的官方 Platform Tools。USB 连接需在手机确认调试授权；无线调试在手机和 Mac 同一网络下配对。配对端口与连接端口分别以手机当前界面为准，不沿用旧会话地址。

```bash
export GAME_CENTER_ADB="$(pwd)/../../03-Android工具/platform-tools/adb"
"$GAME_CENTER_ADB" pair '<手机IP:配对端口>'
"$GAME_CENTER_ADB" connect '<手机IP:连接端口>'
"$GAME_CENTER_ADB" devices -l
export GAME_CENTER_SERIAL='<devices 列表中的目标设备标识>'
"$GAME_CENTER_ADB" -s "$GAME_CENTER_SERIAL" install -r out/game-center-v4.23-dev.apk
"$GAME_CENTER_ADB" -s "$GAME_CENTER_SERIAL" shell am start -n com.dsh.gamecenter/.MainActivity
```

USB 已授权或无线已配对时，执行对应的连接与设备选择步骤即可。`install -r` 用于覆盖安装并保留已有应用数据；本项目必须保持原包名和原签名。签名不一致时覆盖更新会失败，应检查签名材料，避免先卸载而丢失存档。发布版本应增加 versionCode，避免依靠降级安装参数。ADB 命令参考 [Android 官方文档](https://developer.android.com/tools/adb)。

开发版与正式版共用包名，因此一次只能安装其中一版。安装 `Success` 后还要确认应用可启动，页面可操作，后台恢复正常；签名、包内容校验与构建证据见 `out/` 对应 JSON。

## 真机操作与开发检查

一台手机的安装、前台导航、点击、输入、旋转和截图由一个操作者串行执行。并行代理可以改独立文件或跑离线测试，手机操作则由当前负责人协调；每次操作使用明确的 `-s` 设备标识，并确认正在运行的应用和页面。

开发版可用 [phone-cdp.py](scripts/phone-cdp.py) 检查当前 WebView，需在 Python 环境安装 `websockets`。它临时建立 ADB 转发，完成或异常后移除该转发，不自行安装或启动应用。

```bash
python3 scripts/phone-cdp.py '({url:location.href,state:window.__game?.state()})'
```

真机重点覆盖键盘遮挡、语音可用或降级、四个旋转方向的重力输入、倾斜/触摸切换、切后台与明确继续、系统返回、全屏和常亮。Node 测试验证规则与状态，不判断像素效果、设备传感器方向、语音实际发声或玩法手感。

## Mac 与手机 DeepCode 协作

`Game-Center` 作为独立仓库管理。`../../02-DeepCode/dsh-mobile-apk` 是 DeepCode 安卓外壳的上游项目，`../../02-DeepCode/Extensions` 管理本地插件；它们的更新与游戏中心的代码、APK 发布分别进行。

Mac 和手机克隆同一个游戏仓库，Mac 在 `main` 负责主体整合、测试、签名构建；手机 DeepCode 在 `deepcode-dev` 做限定范围修改与设备验证，Mac 审查其 diff 后整合到 `main`。手机仓库使用原开发路径 `/data/data/com.dsharnessmobile.shell/files/home/apkbuild/gamecenter`，原目录先改名备份。源码以 `app/` 为准，手机运行副本、外部 dev 页面和 DeepCode 会话不代替源码版本。Skill、插件、网页和原生壳的更新机制见 [协作流程](docs/development-workflow.md)。

签名密钥与密码文件保存在仓库外，由构建端保管，不提交 Git、不写入日志或 skill。GitHub 同步通过明确的 Git 提交、推送和拉取完成，没有后台自动同步任务。手机克隆公开仓库无需登录，推送需要手机自己的 GitHub 写权限；不复制 Mac 的登录令牌。提交说明使用中文。手机接手说明见 [DeepCode 交接](docs/deepcode-handoff.md)。

临时查询、备份和中间验证产物放到项目根目录，名称带 `TMP to delete`；不用后清理。构建的 `TMP to delete-build` 由脚本自动清理。验收截图和文档属于交付材料，保留在 `docs/`。后续开发约定见 [AGENTS.md](AGENTS.md)。
