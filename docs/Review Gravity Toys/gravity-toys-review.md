# 钢珠迷宫与翻转星星盒 4.18 验收

## 交付

钢珠迷宫整体重构为12个固定关卡，三套配色、宽通道、2～3颗星星、逐步加入钥匙门/洞口/弹柱。120Hz固定步长、倾角加速度、较低阻尼、惯性与反向刹车；掉洞回最近收集点，保留收集，无生命/计时压力。碰撞共同约束墙和圆柱，避免推离圆柱后进墙。

新增翻转星星盒12关：一次倾斜让全部星球一起滑到底，进入同色窝后锁定并可以挡其他球；短解1～8步，支持撤回/重置。无解时只短亮撤回按钮。进入/继续/切倾斜自动校准当前握持角度，迟到样本先校准，暂停/动画期间不补发旧动作。

先用GPT生成三屏视觉原型，再生成共用透明图集；钢珠/星星/钥匙/出口/星球/窝均使用生成美术，墙和障碍按实际几何绘制。原型、完整提示词、来源、桌面截图和硬件调研位于 ../Design Gravity Games/。

## 共享结构

Java/WebView壳、离线HTML/CSS/JS与Canvas/SVG；无npm运行时依赖，无远程CDN。两款共用shared/motion.js、shared/feedback.js和gravity-art.png，通用原生服务只有一份。玩法物理和离散规则分别独立。旧汉字数据和部分CSS仍有各自整理的副本，不宣称所有资源唯一化。

RugeTilt.sample原子读取normalized g/age/source/rotation；TYPE_GRAVITY直读、加速度计按dt低通兜底，后台注销清空。网页按当前握持角度校准，输出sin倾角，超过1500ms失效并有触摸入口。这里使用重力方向，不积分陀螺仪角速度。
