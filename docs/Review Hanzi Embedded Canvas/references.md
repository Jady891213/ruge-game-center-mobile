# 嵌字找字参考

本轮按用户要求搜索并查看同类游戏截图。参考界面中的大字形嵌套关系，使用本项目已获许可字形重新实现，没有把截图或游戏素材打包。

- [九游：《汉字找茬王》口口男找字怎么玩](https://www.9game.cn/hzzcw/8439055.html)：实际通过浏览器打开原图，看到大画布里一个口包着男，左侧另一个口，没有独立字卡边界。
- [18183：国找出20个字](https://www.18183.com/zqnews/202303/4524336.html)：文字说明体现外圈口与内部玉、王等部件的组合。该站原图接口本轮超时，没有把文字读取称作已看过其图片。

实际参考截图只用于本轮观察，放在 TMP to delete 目录，完成后删除。
