# 安卓实体侧滑补验与修复 · 4.34

## 实测发现并修复

1. **暂停“继续”实际点不中。** 接水管的 `button:active:not(:disabled)` 比共享继续按钮的 class 按压规则优先级高，按下后替换了居中 transform。touch/pointer 起止在按钮，但后续合成 mouse/click 已落到遮罩，不会调用恢复。改为唯一 ID 的按压规则。保留[实际触摸记录](touch-retarget-before-fix.json)、[首次失败现场](before-fix-physical-back.json)；没有把只调用 onclick 的测试当成触摸成功。
2. **从翻牌返回时误进帽子旧局。** 手机已有帽子草稿，父页默认恢复旧局，导致“返回帽子入口”实际又进入旧局/暂停层。返回和模式切换明确带 `?menu=1`，父页显示选关与“继续玩”，保留旧草稿；普通从合集进入仍保持原恢复行为。[修复前的实际失败](before-parent-route-fix.json)，新增带旧存档的真实页面回归。
