# 哼哼小飞机 UI（4.29）

## 实现

- 正式 Android 页面进入固定横屏；返回合集及实际离开页面时恢复竖屏。后台暂停不改变方向。
- 游戏世界为 800 × 450；Canvas 根据实际画布和 DPR 等比绘制，多余区域留天空底色。不会因横屏比例拉宽飞机、星星或云门。
- 横屏左侧为大场景，右侧是门数、三颗心、星数和音调反馈；辅助上下按钮可展开。主菜单保留大“开始飞行”、最高门数和次要按钮入口。
- 首次以舒适的“啊/哼”校准约 0.85 秒。高音连续上升，低音连续下降，中音及静音保持高度。新一轮和后台明确继续复用本次会话的舒适音域，不反复提问玩法。
- 暂停、后台、离页立即停止音频；回前台保留暂停，须点“继续飞”。异步开麦使用请求序号，取消后旧 Promise 不得重开游戏。
- 音控中的得分、收星和碰撞只触发短震动；避免本机扬声器音效被误收为操控声音。
- 只有新的 `rugePitchFlightV1` 记录最高云门数及最高单轮星数；不读取或写入旧关卡/旧无限跑存档。

## 美术与碰撞

- 使用根任务生成的 `art/flight-sky.png`、`art/flight-sprites.png`，源矩形来自 `art/flight-art.js`。
- 飞机根据升降切换抬头/平飞/俯冲帧，平飞两帧轮播；另有轻微桨动画、气流拖尾、收星颗粒、受击闪光和护盾圈。
- 云门实际墙宽与核心 `width` 相同；装饰云帽全部在开口边界之外，不遮挡可通行区域。
- `?cover=1` 为固定真实场景，不开麦、不推进、不读写存档，也不触发方向切换。

## 测试入口

`window.__game` 提供本游戏控制与观察接口：`beginVoice / beginTouch / pause / resume / menu / restart / hold / frame`，以及只读 `engine / state / paused / save`。

VM 验证覆盖生命周期与异步边界，真实 Chrome 用于场景、图片及布局检查；声音真实手感仍需由根任务通过 MIX 4 验收，不把音高样本夹具当成真人演唱。
