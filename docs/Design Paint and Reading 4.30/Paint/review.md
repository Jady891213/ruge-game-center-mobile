# 小小调色师 4.30 视觉更新

## 结果

先用内置 `image_gen` 生成竖屏 UI 原型，再生成八个灰度可上色角色素材，替换旧版手写角色路径。保留红、黄、蓝、白逐滴调色、10 关 14 个目标、自由画室、原存档和距离不大于 17 的通过规则。

- 原型：`paint-ui-prototype.png`；实际打包素材：`app/assets/paint-mixing/art/paint-friends.png`。
- 提示词：`imagegen-prompts.json`；生成来源、哈希与裁切信息：`generated-art.json`。
- 普通常见的连续色盘替换离散可达色点。星星是目标、圆点是当前颜色，保留最近调色轨迹和实时分数。颜色越淡越靠近中心，右侧单独对照亮度。
- `wheelPoint()` 只把真实 RYB 混色结果映射到标准 HSV 圆盘；圆盘的色相从正上方红色顺时针、饱和度向外增加。右侧用 V 表达亮暗。没有把颜料混合改成 RGB 相加；它也不是承诺真实颜料品牌的物理模型。
- 竖屏以大色盘为主，横屏将题目、色盘、颜料操作分成三块。392×872 色盘有效直径约 263px；320×568 约 162px，保留全部大按钮。

## 验证

- 19 项相关 Node 回归通过（原测试保持），覆盖原混色/订单/恢复/暂停，以及连续盘坐标、所有可达配色的 HSV 还原、加白向中心移动、实际页面两类标记。
- `browser-qa.py` 使用真实 Chrome，在 320×568、392×872、568×320、872×392 逐一点击加滴、上色，检查无页面溢出、按钮可见、圆盘无拉伸。所有 14 个目标实际点击原配方通过，无 JS 异常。结果：`browser-qa.json`。
- 截图包含 `empty-*`、`mixing-*`、`painted-*` 和 `white-tint.png`；已目视检查四尺寸，尤其小屏下图集必须显式 clipPath，避免 SVG 留白露出相邻角色。着色 filter ID 按形状和颜色区分，避免隐藏菜单角色抢占颜色。
- 浏览器、独立临时 profile、HTTP 服务均在 finally 关闭，结束后无本轮 profile 相关进程。
