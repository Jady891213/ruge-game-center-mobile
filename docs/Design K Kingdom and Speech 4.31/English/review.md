# K国王回家 · 4.31

## 已实现

- 原创 K 字母国王横屏英语故事游戏。K 有待机、走路、施法动画；成功后坏队缩小飞走、冰块融化、伙伴跳起，20关末回到家。
- 20关、37次挑战，固定包含 me / dad / mom / bed / apple / banana / sister / brother / computer。1—6关完整拼写提示，7—12关首字母提示，13关起隐藏文字提示；始终保留词图和按需英文示范。
- 先用大字母块拼写，也支持实体键盘。拼写错误不扣心；拼对后读目标单词，只有真实专业评分通过才加分、施法、继续。
- 每关5心。有效确认的错词或低分扣1心；静音、网络、权限、服务异常、评分结构损坏不扣心，也不给假0分。5次有效失败重试本关，分数和心重置；已完成关卡记录保留。
- 原始总分≥75、唯一词准确度≥70、词匹配且MatchTag为0才通过；不得用ASR置信度代替发音分。
- 独立存档 `rugeEnglishKingdomV1`，仅保存解锁和每关最佳分，无凭证、录音、服务会话。后台停录音、关云连接、停示范，回到前台明确继续；迟到结果不推进、不扣心。胜利面板后台不会丢失。
