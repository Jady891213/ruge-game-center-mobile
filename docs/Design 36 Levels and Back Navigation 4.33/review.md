## 安卓返回层级

原生先交给当前页面的统一返回处理；页面按状态消费一层，游戏根页才回游戏中心，游戏中心再返回退出。不依赖WebView浏览历史，不使用超时强制跳首页。普通弹层先关闭，暂停内容不会意外恢复物理或开麦；确认、详情、选关和子玩法分别处理。

典型路径：

- 识字库出处 → 汉字详情 → 字列表 → 原入口（从打字进入则回打字菜单，从合集进入则回合集）。筛选/列表位置保留。
- 看字打拼音统计/练习 → 打字菜单 → 合集；开口读拼音弹层 → 当前练习 → 打字菜单。
- 翻牌本局 → 翻牌选关 → 帽子入口 → 合集。
- 自带棋盘的接水管/钢珠/字里找字 → 本游戏选关根页 → 合集；主动点开的普通选关弹层先关闭回原本局。
- 语音/相机游戏离开本局停采集；返回游戏入口保留已有草稿和成绩。
