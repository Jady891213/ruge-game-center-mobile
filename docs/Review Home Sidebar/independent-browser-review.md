# 首页侧栏布局独立浏览器验收

日期：2026-10-18。使用真实本地 Google Chrome 无界面实例与 CDP，读取当前产品 HTML/CSS/JS；未操作手机，未修改产品源码。

## 结果

五组视口均通过：320×568、392×872、430×932、872×392、800×320。未发现需阻断交付的缺陷。

- 全部页固定两列，共 12 款游戏；320px 小屏全部标题可完整显示，包括“小青蛙跳池塘”，未使用截断省略。
- 左侧分类为全部/最近/认字/益智/重力/反应；六个分类按钮中心均命中自身，短屏 800×320 左栏底部仍在视口内。
- 页面的 document 和 body 尺寸等于视口，无整页横向或纵向滚动。右侧列表滚到底后，标题栏与左侧分类的实际坐标保持不变，window.scrollY 仍为 0。
- 重力分类准确显示钢珠迷宫/数字碰碰/翻转星星盒三张。
- 最近空记录显示“还没玩过”；注入包含下架点心店的真实格式历史后，按 last 降序只显示仍在架的三款。未修改原历史过滤逻辑以外的存档。
- 实际浏览器点击最近第一张卡片进入字里找字，浏览器返回后 plays 增加一次，证明导航和记录写入监听正常。
- 音效、震动、常亮三个独立图标均可实际点击；开启/关闭状态通过背景色、斜杠及 aria-label/aria-pressed 一起变化，无常驻文字。

## 证据与边界

- `browser/results.json` 保存五组视口的卡片几何、所有按钮命中、滚动前后坐标、分类/最近排序及独立图标状态。
- `browser/` 含五组视口的全部顶部/底部、重力、最近空态/排序、关闭图标截图，共 30 张。
- 桌面 Chrome 验证不代表 Android 原生桥、触觉强度或真实硬件方向；手机由主代理单独验收。
- Chrome 主实例/专用 profile 及子进程在 finally 关闭清理；进程复查无相关 profile 残留。
