# 汉字小书架 UI（4.26）

## 已实现

- 独立字库：沿用资料中的原有分组，支持汉字、繁体与有／无声调拼音查找。大字卡显示带声调拼音，不读取或写入任何游戏存档，不把收录或练习当作“已经学会”。
- 讲字详情：现代规范字、读音、短义、简短字源故事；真实历史字形横向浏览，若古形对应繁体，先展示“繁体今字／现代印刷字”，再到“今字／现代规范字”；两张现代字卡均为系统字体单独标注，不冒称古楷书原件。没有收录早期字形时明确说明资料缺图，不把缺图说成历史不存在。
- 长资料收折：出处标题、可长按选择的网址、复制链接；原生 `RugeNav.openSource(url)` 可用时提供“浏览器打开”。所有来源经 HTTPS 校验，不在 WebView 强行加载外站；图像只允许库内相对路径。
- 回列表保留搜索、分组与滚动；详情可前后翻字；支持 `#char=日` 深链。点朗读才朗读，后台与退出停止，恢复前台不自动重读。
- `?cover=1` 为真实页面封面模式，只展示前三张字卡，不读写存档，不进入深链详情。
