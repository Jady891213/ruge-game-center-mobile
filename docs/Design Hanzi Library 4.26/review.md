# 汉字小书架 · 4.26

## 入口与内容

- 首页「认字 → 识字库」，以及「看字打拼音」菜单里的「识字库」。本轮增加资料入口，不增加新练习题，保留原6组60字及判题读音。
- 汉字、繁体、无声调拼音搜索；每字有大字/读音、短释义、字的故事、古今字形、折叠的出处与谨慎说明。回列表保留筛选与位置，支持前后字与点按朗读。
- 全60字有逐字来源及精简说明；47字含108张公开古字形摹本选例（甲骨、金文、篆文按实际查证展示），不是60字都具有完整三阶段。13字暂不含古形图片，仍显示现代字/必要繁体及原因；例如这、你、们等后起字不伪造甲骨文。
- 正文/图像全离线。用户主动点击出处才交给系统浏览器，应用继续不具有INTERNET权限，不在WebView执行远程资源。

## 字源与字形边界

资料以[香港中文大学《汉语多功能字库》](https://humanum.arts.cuhk.edu.hk/Lexis/lexi-mf/)为主，补充汉典和教育部异体字字典；每字直达页面在[data.json](../../../app/assets/hanzi-library/data.json)。research-a/b保留逐字整理底稿，原拼音练习的接受读音不因字典其他读法而变化。

- 只与隻、里面的裏与乡里的里、助词的与相关旳、以与㠯明确分支，不把近形或后来的助词义直接讲成象形。
- 起的争议金文没有纳入；部分字的早期本义仍有不同解释，正文保留“一说”等表达。没有本轮图片，不代表历史绝无该阶段。
- 108张SVG取自固定版本的公开Commons字形词典镜像，按字/阶段取一个摹本，不是原文物照片或完整连续谱系。逐图原页面、许可、作者、镜像片段和包内SHA见[form-sources.json](form-sources.json)，统一许可说明见[第三方许可](../../../THIRD_PARTY_NOTICES.md)。不使用GPT或现代篆体补古字。
- 镜像已将SVG嵌进HTML；包内仅清理无关编辑器属性、规范展示尺寸，矢量路径保留，不声称与当前Commons原始字节完全相同。固定镜像Git blob已校验。
- 繁体今字/今字使用现代系统字体，单独标示，不冒称古代楷书。字库展示当前练习字表，不把分数或收录等同孩子已掌握。

## 后续维护

新增字或修订解释先修改共享词表/资料来源，保持data.json与catalog.js一致；明确历史字形阶段、来源字与许可，不因字典里有某个现代篆体而扩大古文字收录。字库没有独立掌握进度；如以后需要“已学会”，应新增明确的家长标记或逐字练习记录。
