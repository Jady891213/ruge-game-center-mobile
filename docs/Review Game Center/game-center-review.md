# 游戏中心审查与本地改造

日期：2026-10-04。设备：小米 MIX 4，Android 14。

## 当前结论

原项目是一个 Java WebView 外壳加七个离线 HTML 游戏。这个结构适合当前的小游戏合集，可以继续使用。代码已从手机迁移到 Mac，保留迁移前的源码和 APK，当前开发源码位于 `app/`。

建议以后由 Mac 负责完整开发、测试、美术整合和签名构建；手机 DeepCode 用来现场试验、定位设备问题和提交小补丁。两端可以使用同一个游戏 GitHub 仓库、各自任务分支。上游 DSH Mobile APK 外壳、游戏中心、DeepCode 扩展分别管理。

## 返回、常亮和生命周期

- 系统返回：任意游戏页回游戏中心首页；首页再次返回才退出。Android 14 显式启用旧 Activity 返回回调，判断当前入口 URL，不依赖 WebView 是否恰好有历史。输入法打开时，系统通常先收起键盘。
- 游戏中心：前台窗口 `FLAG_KEEP_SCREEN_ON`，首页可关闭并保存选择；后台清除，回前台恢复。游戏暂停后回前台需明确点击继续。
- DeepCode：独立 `screen-awake` Cordis 扩展，使用浏览器 Screen Wake Lock，设置位于“设置 → 常规”。持续安装及设备验收见`../../../../02-DeepCode/Extensions/screen-awake/README.md`。
- 视频应用不熄屏通常来自应用主动请求保持屏幕亮，不是特殊的“视频播放权限”。参考 [Android 官方说明](https://developer.android.com/develop/background-work/background-tasks/awake/screen-on)。

开发版原本回前台会无条件重载，本轮已改为仅外部开发资源变化时刷新。普通后台恢复保留当前游戏页面和状态。

## DeepCode skill 与插件审查

| 资产 | 判断与建议 |
| --- | --- |
| html5-mini-game | 引擎、公平性和简单测试约定有用；强制单 HTML、没有外部素材会限制维护和美术。允许离线 assets、共享 renderer、模块化逻辑与关卡数据，增加实机生命周期验收 |
| android-apk-build | 手机工具链排坑可参考，硬编码路径和手工步骤不宜成为主构建链。本地 `scripts/build.py` 统一构建，签名材料在仓库外 |
| android-device-automation | 权限与操作证据意识有用。“全部操作一条 shell 命令”过于绝对，应保留状态等待与检查点 |
| create-skill | 加载、命名与元数据校验有用，加载成功不能证明生成代码、美术或游戏质量合格 |
| hanzi-find-game | 是特定第三方小游戏的自动化经验和固定坐标，不是本游戏中心的开发规范，作为个人参考保留 |
| skill-manager 插件 | 本地修复真实路径/软链接越界、只读根、`.system`、目标名一致性与原子写入；55 项测试通过。当前未替换手机正在使用的插件 |

技能不能替代项目级源码和测试。以后让 DeepCode 修改游戏时，先给它本仓库 AGENTS、具体任务和验收条件，修改完成提交 diff，由 Mac 整合。

## 验证边界

- 游戏真实脚本回归 34/34；无 npm 运行依赖。
- 4.2 正式 APK 已用原证书覆盖安装到 MIX 4；设备 APK 与本地最终产物逐字节一致，全部 assets 与当前源码一致。版本与校验记录见 `verification.json`。
- 最新正式版已在解锁后实测：接水管左右侧滑都回游戏中心首页，首页再次侧滑退出游戏中心；恐龙正在游戏时侧滑也回首页。
- 恐龙暂停时切到桌面再回来，分数仍为 20、最高分仍为 1505，仍停在暂停面板；点击继续恢复。游戏中心常亮关闭后系统 `mHoldScreenWindow=null`，打开后持有游戏中心窗口。
- DeepCode 标准扩展正常重启后进入 boot graph；前台实际常亮，开关关闭在页面重载后仍关闭，后台释放。验收时临时将系统熄屏阈值改为 15 秒：前台 21 秒后仍亮，后台 20 秒后正常休眠；随后恢复原 10 分钟。正常解锁后前台再次持锁。未做持续 10 分钟的原阈值等待或长期耗电测试。
- 新版恐龙和小鸟入口的真实预览已在手机目视确认，与游戏里的角色一致。最新证据是 `10-center-final.png`、`11-after-left-back.png`、`12-dino-intro-final.png`、`14-dino-resumed-paused.png`、`15-bird-intro-final.png`。较小编号为前一轮过程截图。
- Android 正式/开发 APK 由官方 Build Tools 构建并验证签名、包名、版本、ZIP 对齐及全部 assets。
- 已逐页查看七款游戏，并检查关键实际触摸、输入法、传感器与暂停操作。截图位于 `screenshots/`，旧版对照在 `screenshots/before/`。
- VM Canvas 不画图；它验证逻辑，不证明视觉质量。自动可达性不等于手感和关卡好玩。这轮没有人工通关全部关卡，也没有做长期耗电测试。
- 截图左侧辅助按钮与右侧鲸鱼悬浮球来自手机其他服务，不是游戏中心的界面。

更完整的下一轮应优先做固定关卡节奏和成长目标，再做角色逐帧动画、环境细节和音效；当前改善属于可继续迭代的小游戏版本。
