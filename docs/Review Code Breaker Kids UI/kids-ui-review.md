# 小小密码箱：儿童界面调整

本轮按用户试玩反馈重做界面。版本 **4.4 / versionCode 27**，已覆盖安装到 MIX 4。

## 调整

- 去掉首页口号、关卡名称与说明段落、教学入口、输入说明、线索说明、提示入口、正常反馈解释句；关卡只留数字、星星或锁图标。
- 游戏画面只保留返回、关卡/位数、尝试计数、输入格、历史、三列数字键盘与「打开」按钮。
- 历史只显示两类反馈：绿色方框勾代表数字和位置都对，黄色交换箭头代表数字对但位置错。取消灰色错误数量，数字本身保持中性色。
- 放大输入、历史数字、反馈数字和按钮；清空/删除用 SVG 图标，避免 Emoji 因系统变化不清楚。
- 使用圆润粗字体、奶油色背景、薄荷绿/暖黄反馈、柔和粉色入口和自行绘制的笑脸锁头；封面重新从真实游戏界面生成。
- 结果弹窗只保留简短标题、答案、星星和继续按钮；随机模式只保留位数与「不限/挑战」选择。
- 原来的 18 关、2/3/4 位规则、随机模式、存档与系统返回保持原有契约。必要的无效输入反馈为短暂词语，正常游玩没有解释文字。
