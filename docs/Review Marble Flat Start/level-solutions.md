## 第13关问题与当前球位

旧判定预留了转轴周围整个半径89的圆，错误拦住转轴上方/左侧的安全位置。挡板实际只扫过转轴右下90°区域。现判定为该扇形加挡板厚度、端帽、钢珠半径和下一物理步余量，仍拒绝真正扫到球的转动。

转轴(80,144)，本轮设备存档球(126,98)，以及回归样例(90,114)/(116,100)/(48,176)均在安全侧，新版可直接转动；不移动球、不挤球、不丢收集。若球已经进入右下扫掠区，则先退到左边或上边空位再点挡板。第13关从开局的完整路线如下：上、上、点1号挡板、右、右、上、上、右。
