# 钢珠迷宫：独立只读复核

日期：2026-10-18。复核范围为关卡、实际规则物理、挡板扫掠、水平启动和存档兼容；此复核未操作手机，也不代替主操作者的真机验证。

## 第13关现场问题

- 旧版关卡存在解法：从起点到第12格附近先旋转挡板，再经过8、9、10、6、2格到3格终点；不是关卡拓扑本身无解。
- 旧版 `rotationClear` 把轴周围半径89的整圆都视为危险区，实际挡板只经过右下90度区域。现场原存档球位由主操作者读取为(126,98)；独立回归另用(90,114)代表轴上方的安全空地，两者不能混作同一坐标。轴在(80,144)时，(90,114)合法但旧代码拒转，与现场截图表现属于同类过度拒转。
- 原来的规划按钮还增加了一层隐藏操作。新版直接点轴转动，取消该前置步骤。

## 挡板防夹球

- 独立构造旋转矩形碰撞模型：长边范围[-4,68]、短边[-4,4]，将球坐标按每个角度逆旋转后计算圆与矩形碰撞。
- 在轴周围[-110,110]、间隔2像素的点阵中，对新版判定允许的9756个位置，各扫描0～90度的361个角度（步长0.25度），危险放行数为0。
- 原现场代表点(90,114)现在允许；右下扇形内部仍拒转。允许操作的安全区没有退回整圆限制。
- 有限采样验证与代码的包络证明相互补充，不把有限采样称为所有连续坐标的穷尽证明。

## UI及传感器独立VM复核

执行真实打包HTML、shared/motion.js和game.js，5组均通过：

1. 手机倾斜约30度时阻止开局，显示放平图；屏幕朝上、水平偏差不超过8度且姿态变化不超过2度，持续半秒后自动开始。旧touch偏好不会改变有原生传感器时的默认倾斜；即使调用校准也不能把倾斜姿态改成水平零点。
2. 取消引导、切后台再回前台、打开选关、转屏，都取消待开始状态；之后单纯放平不会自动开始旧的等待请求。
3. 年龄301ms的读数不能满足启动水平门禁，保留等待检测且不显示多余方向盘选择；恢复新鲜样本后重新稳定才开始。
4. 有原生桥但传感器确实不可用/数据超过1500ms时，引导只显示必要的“用方向盘”按钮，点击后降级并开始；不会静默切换孩子正在使用的原生倾斜模式。没有原生桥且没有网页有效样本的普通浏览器预览，会自动使用方向盘。
5. 第13关在安全位置直接点击挡板轴即旋转；危险位置拒转且球/朝向/进度保持；后台点击不生效。

VM只验证状态和交互逻辑，不能验证实际触摸命中尺寸、美术、原生方向、真实手持灵敏度。

### 最终杆身点按复核

最终冻结源码的相关45项测试通过（marble-maze、marble-simple-ui、motion）。杆身点击以实际 `rotorWall` 为命中几何，容差22 CSS像素；短点小于700ms、移动小于12 CSS像素，拖动/长按/取消/遮罩/后台均不会触发。独立补测双指隔离和鼠标右键：第二指的抬起不会代替主指触发，主指完成只转一次；右键不旋转。轴上的DOM按钮与Canvas为兄弟节点，不会重复提交。
