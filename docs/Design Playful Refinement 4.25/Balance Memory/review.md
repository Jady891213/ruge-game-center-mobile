- 保留前两关的直接替换教学。第3～18关每题三幅比例图，需组合至少两条线索；题面的目标组合不能原样复制到答题盘，也不能从一条提示直接照搬答案。

- 六种水果固定重量仍为1/2/3/4/5/6，不换模型、不暗改同一种水果重量。保留点放/拖动、取回、真实阻尼秤杆、称重和暂停机制。
- 存档仍为 `rugeAnimalBalanceV1`，schema升为3：旧schema1/2的18关星数/解锁保留，旧题草稿失效。新schema3草稿按新库存、盘数、数量条件和称重结果验证。
- `fruit-level-audit.json` 列出真实core的18关题目、库存、全部完整答案及一个可直接重放的id答案。测试对第3～18关的每个可行局部盘都做线性空间检查：三条线索足够推出平衡，任意一条单独不足；不是只检查某个预设答案。

例：第3关用“橘子=两草莓、苹果=橘子+草莓、梨=苹果+草莓”，推得梨可以换成两个橘子。题面没有直接写“梨=两个橘子”。后面加入组合目标与数量限制。
