# 唱跳小兔与口令小冒险 · 4.25

## 改动

### 唱跳小兔

- 保留 `pitch-adventure` ID、18 关和旧存档键 `rugePitchAdventureV1`，标题换成“唱跳小兔”。
- 用内置 `image_gen` 生成原创小兔 12 帧透明图集：4 个跑姿、跳、落地、2 个低蹲、2 个碰撞恢复、2 个庆祝。真实 alpha 裁切框等比绘制，动作按钮也从实际帧绘制，不拉伸格子。
- 高音跳、低音蹲。动作只读取 `pitch / baseline`；RMS 只用于拒绝静音和显示收音反馈，不能用喊得响代替高音。现有相对音域校准和安静启动保留。
- 树枝必须蹲下经过，坑/石头必须跳；原 18 关前疏后密，保留儿童输入预约和安全动作窗口。
- 增加“一直跑”：每 4 个障碍提升一段，95→140 世界单位/秒渐进加速，障碍间距 360→300 渐减；坑宽由 50 增至 72。3 次失误结束，可以重复挑战。最高段数只存到新键 `rugePitchEndlessV1`，不覆盖原关卡草稿、星数、解锁。
- “试声音”继续原地安全练高低音；切后台停止收音，回前台明确继续。

### 口令小冒险

- 默认语音、下一关不再询问模式，触摸辅助仍可展开。
- 增加“往左/往右/左边/右边”等绝对方向；“前进/往前/向前”“后退/往后/向后”相对当前朝向，后退不会偷偷转身；“左转/右转”只改变朝向。
- 场景右上角四向标识高亮当前朝向，角色脚边继续显示当前箭头。
- “拿起/拿起来/捡起来”“放下/放下来”；携带物品并走到匹配目标后，可说“开门/打开门”“喂小兔/给兔子/交给兔子”“送回家/放进窝”。语义任务在目标、携带物或位置不匹配时拒绝，不能靠“开门”在地图任意位置过关。
- 下方口令表可独立上下滚动，家长可查看固定可识别说法。长句仍不是自然语言理解；不宣称任意说法均支持。
- 18 关布局、旧携带物和朝向存档兼容。求解器继续使用原绝对方向+跳/拿/放，不让新增同义动作改变旧关解。

## KWS 检查与调整

固定 `sherpa-onnx 1.13.8`、WenetSpeech 3.3M mobile encoder/decoder/joiner/tokens 与两份原生库，未换模型、未联网。官方 [KWS 文档](https://k2-fsa.github.io/sherpa/onnx/kws/index.html) 说明逐词 `:score`、`#threshold` 和增大 trailing blanks 处理重叠词；本轮也经 Context7 查询官方源码 API。

原问题有可定位的两部分：

1. 原词表直接把“前进”映射 `up`、“后退”映射 `down`，未考虑当前朝向；“往左、开门、给兔子”等没有配置。
2. 扩展词表后短前缀可能提前触发。实音对照中 `maxActivePaths=8, trailingBlanks=2` 对一句无关句误触发 `up`；增为 4 个 trailing blanks 后这组误触发消失。没有全局盲降阈值。保留多字词 `#0.15`、单字“跳” `#0.50`；“往右/往后”补声调变体并给特定词 `:3.0 #0.12`。

词表中的“向左转/向右转”会和“向左/向右”抢前缀，故页面只公布“左转/右转”，不宣传带“向”的转身长句。单字“跳”仍有高阈值保护，页面教“跳一下/跳起来”。

### 固定语音对照

在 Mac arm64 用同版 host KWS、同三份 ONNX、16 kHz PCM，每 512 样本喂一次，并保持与 Android 相同的 reset 规则。合成语音直接进模型，**不含麦克风、房间噪声或儿童语音**。这是配置/词表覆盖对照，不是儿童识别率。

|配置|Tingting 190 wpm，49 样本|
|---|---:|
|旧词表、4 paths / 2 blanks|21 符合新动作语义|
|初版新词表、4 paths / 2 blanks|42|
|初版新词表、8 paths / 2 blanks|43（包含一次无关句误触发）|
|初版新词表、8 paths / 4 blanks|45|
|最终词表、8 paths / 4 blanks|47|

49 样本由 38 条页面公布的口令、8 条无关句，以及 3 个刻意保留的边界“向左转/向右转/跳”组成。最终 Tingting 的 **38 条页面口令、8 条无关句全部符合预期**；“向右转”会先命中向右，单字“跳”漏检，未隐去这些失败。

第二组 Meijia 210 wpm 的 49 样本为 43 符合；页面公布的 38 条中 35 条符合，**往左、往前、往后仍漏检**，8 条无关句均未误触发。说明覆盖与部分配置已改善，但口音、速度、儿童发音、背景声仍需真机试玩，不能把一次合成声成功写成稳定识别率。
