# 字里找字：答案库补漏（4.17）

## 原因与判定方式

之前是手工整理的固定答案表：以完整笔画索引集合查找汉字。Hanzi Writer数据只提供字形/中线，不提供所有可拆出的字；游戏没有OCR、实时联网字典或每次由模型判题。原表漏掉田的[2,3,4]→土，导致合理选法被判错。

本轮复核60关，补入14个关内答案、28种完整笔画选法。共358个关内答案、673种合法选法，最多单关12字。完整实际数据见 answer-inventory.md / answer-inventory.json，新旧差异见 answer-delta.json。

## 统一复用

answer-catalog.js汇总旧规则、同一实际字形及部件的答案，再添加reviewed审校补充；按composites.strokeMap将标准笔序映射回关卡全局索引。独立早和日十组成的早共享所有答案，田→土自动复用到思、男。所有旧合法选法保持，新增选集不得与其他字歧义。

本轮依据完整几何允许合理比例变化。王[0,1,2]的竖明显穿出下横，仍认干；不只看横长短改认士。生/青去部分笔后的竖明显出头，不硬认王。保留原有多字关整笔/部件重组规则与二三的跨字选法。

## 后续维护

先检查整笔字形，再向reviewed添加标准笔序选集；统一复用会覆盖同字/同部件关卡。运行审计导出实际清单，再执行回归和真机触摸。对于同一选集可能对应不同字、或必须拆折笔/旋转才能成立的候选，先明确交互规则，不能通过多收答案掩盖歧义。
