# 钢珠迷宫重构与离线验证

## 已实现

- 原“滚珠花园”重构为“钢珠迷宫”，保留 `gravity-maze/` 路径。共12张固定迷宫，依次为薄荷花园、晴空小岛、珊瑚乐园三个主题，每主题4关。
- 房格从3×4、4×5逐步扩大至5×6。手工设计主路线，额外房间为确定性的短支路；钥匙在对应门之前，不存在绕门通路。每关2～3颗星，全部收齐后到绿色出口通关。
- 前三关无坑，无倒计时、命数或失败扣分。后续出现少量明显深色洞和粉色弹性障碍；掉洞回最近收集点，保留星星与钥匙，可无限重试。危险安排在支路，主路线始终能安全通过。
- GPT生成图集 `shared/gravity-art.png` 被两个重力游戏共用。钢珠、星星、钥匙、出口按紧贴实体的矩形裁切，避免等格裁图时透明留白造成可见球与碰撞球不一致。钢珠无笑脸；迷宫墙、底板由Canvas绘制，不添加假木纹。
- 关卡、收集、钥匙、物理、草稿恢复在 `core.js`；输入、生命周期、存档和Canvas绘制在 `game.js`。页面共用 `shared/motion.js` 和 `shared/feedback.js`，无新第三方运行时包。

## 手感与碰撞

- 物理采用120Hz固定子步，钢珠半径14世界单位，房格64，墙宽8。加速度为2600×校准后倾角正弦，10°倾斜约452世界单位/秒²；未放大微小倾斜至饱和。
- 阻尼0.72/秒、速度上限220世界单位/秒。回平后保留滚动惯性，反向倾斜制动；这是屏幕游戏的可控近似，不能称为真实尺寸钢珠的精确物理模拟。
- 每子步位移不足2世界单位，墙与弹性圆采用联合迭代约束。极端紧接触不收敛时保留上一安全子步，避免弹性障碍把钢珠推入墙内；存档也拒绝墙内或障碍内位置。
- 触摸方向盘读数按0.24缩放，模拟约14°最大倾角。第二根手指不抢输入，松手或取消清空方向。传感器过期不允许开始/继续；游戏中持续失联会暂停，并保留“用触摸继续”入口。
