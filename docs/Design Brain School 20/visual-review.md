# 脑力游乐园：知觉四玩法验收

## 实现

- `shape-parts` 分解拼图：种子生成连通、多片无重叠目标，提供不同形状干扰片。正确选片自动归位，全部找齐后计分。目标保留细拼缝界定每一片，避免随机轮廓存在另一种合法分解、却被判错的歧义。
- `shadow-shift` 旋转剪影：复用GPT透明图集，真实轮廓旋转、漂移及多物体遮挡。多选对应物品后提交。
- `train-turn` 连接轨道：随机自避网格路径，按列车的相对朝向补左/直/右轨；列车真实沿路径移动，补完所有缺口、到站动画完成后才计分。
- `true-view` 选择视角：用真实3D坐标、立方柱高度、正交相机yaw变换与深度排序绘制。箭头在世界坐标中指定观察方向，候选由同一3D场景的不同相机方向投影生成。“转一转”改变主场景观察方向，目标世界方向不变。
- 没有引入远程依赖或每游戏单独引擎；几何渲染使用离线SVG。

## 规则与输入测试

执行：`node --test tests/brain-visual.test.mjs`，10项全部通过。

覆盖10档难度下4200组随机题：拼图800、剪影1000、轨道1200、视角1200。除check/solution匹配外，独立验证连通/无重叠、路径单步几何/无自交、相对转向的向量叉积、3D四向变换公式、候选投影可区分、错误及重复答案拒绝。另检查真实mount的按钮输入、暂停门禁、剪影运动、拼片归位和列车移动到站后才提交。

工具：Tabbit CLI，独立临时任务“脑力知觉验收”。实际加载当前打包HTML文件，使用Playwright按钮点击；未直接调用api.answer替代交互。

- 392×872，四游戏各从1级启动并实际点击答对一题：每题135分、0误答。
- 320×568，四游戏各从10级启动并实际点击答对一题：每题360分、0误答。轨道完成5次补轨及整条列车移动，约5.1秒后计分。
