# 脑力游乐园：20种随机玩法

## 需求与实现

在 `feature/brain-school-20` 开发。首页新增“脑力游乐园”，内部五类各4种玩法，保留原19个入口。共用Android/WebView外壳、声音震动、原创图集、计时评分和导航，全部资源离线。无新权限、网络服务或额外游戏引擎。

规则参考 [任天堂Switch《灵活脑学校 一起伸展大脑》](https://www.nintendo.com/tw/switch/azlsa/stretch/)；[英文清单及实机图](https://www.nintendo.com/sg/switch/azls/index.html)。研究阶段逐项看过20张官方截图；项目不打包其美术、代码或商标。下表描述本项目实际实现，数量和难度为适合儿童的改编。

## 共用挑战机制

- 每局60秒，持续随机出题，无固定关卡上限；每答对3题升一档，最多10档。新一局换种子，可以用同一份素材重复生成不同题。
- 正确基础分为 `100 + 25×当前档位 + 10×min(5,连击)`；错误扣 `25 + 5×档位` 分并扣1.5秒，分数不低于0，清连击。同一次正确不能重复计分，连续误触有450ms门限。
- 每个玩法独立记录最高分，唯一新键 `rugeBrainSchoolV1/schema1`。不读取或重写旧游戏进度。
- 记忆展示、洗牌、下落、列车行进都由有效游戏时间驱动。后台和暂停冻结时间/阶段；回来需要明确继续。实际前台帧卡顿不延长60秒挑战。
- 返回路径：游戏中先暂停，暂停再返回玩法详情，详情返回20玩法集合，集合再回游戏中心；暂停菜单也可直接选玩法。开始新局或换页面清除上一局反馈气泡。

## 美术与3D

- [GPT界面参考原型](ui-prototype.png)、[生成说明](art-prompts.json)。应用实际使用 [原创透明图集](../../app/assets/brain-school/sprites.png)，12种角色/物品共用，各主体采用精确裁片范围、等比例缩放，防止相邻格露边。
- 界面采用奶油底、薄荷绿/天蓝/暖黄、圆角、大数字、大按钮和短题目。基础几何、天平、时钟、轨道与3D投影用代码绘制，以便题目随机组合。
- 积木计数和视角题使用实际3D坐标、正交投影、面片排序及遮挡。没有安装20份依赖，也没有在页面中用静态图假装3D。

## 验收证据

- Node真实规则回归：`tests/brain-*.test.mjs`，覆盖五类20玩法、多随机种子、10档难度、独立可解性/唯一性约束、非法答案、重放物理与计时评分。旧项目测试一并运行。
- [直觉/数字浏览器记录](browser-identify-compute.json)：8款×两尺寸×1/5/10档，48题，实际鼠标点击通题、连续换题和暂停。
- [记忆浏览器记录](memory-browser-qa.json)：4款×两尺寸×1/5/10档，24题及2组层级/暂停检查。
- [分析浏览器记录](analysis-browser-check.json)：4款×两尺寸×1/5/10档，24题；含雕塑删除、撤回和暂停。
- [空间浏览器补验](visual-review.md)：4款初级/高级实际点击，含列车补齐多个缺口并动画到站、3D观察和两尺寸布局。
- [补图可见线索补验](frame-clues-browser-check.json)：独立按4角连续线索推导答案，修复过整格盲猜问题。后续候选统一四列，避免小屏3+1挤出底部。
- [手机触摸记录](phone-review.json)：仅记录实际结果；脚本读取题目作为自动化驱动，答案通过真实成套触摸输入，不调用 `api.answer` 代替操作。包括全部20款、连续换题、暂停与系统边缘返回，测试结束精确恢复用户原存档。

复验脚本位于 `scripts/verify-brain-{school,memory,analysis}.mjs` 与 `scripts/verify-brain-phone.py`。桌面脚本使用本机Playwright/Chrome作为开发工具，不进入APK；浏览器/context在finally关闭，手机脚本在finally清理自建ADB转发。

随机样本与自动指针证明规则、状态和交互链路；儿童是否觉得有趣、难度是否合适，仍需实际试玩反馈。未将自动化测试记作儿童人手体验。
