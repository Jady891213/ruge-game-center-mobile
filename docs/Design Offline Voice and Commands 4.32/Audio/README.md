# 游戏朗读统一离线示范（4.32）

## 已完成

全部有朗读的页面现在只使用 MiniMax 预生成的本地 MP3，通过同一份 `shared/demo-audio.js` 播放。沿用4.31的101条资源，朗读迁移没有新增合成请求、密钥、包内音频、网络端点、依赖或权限。口令识别另生成12条MiniMax合成诊断音，仅放验证文档、不进APK，详见上级报告。

| 入口 | 映射规则 | 复用资源 |
|---|---|---|
| 看字打拼音 | 当前汉字 + 共享字库明确的首读音 | 60条默认读法 |

| 开口读拼音 | 当前 `ReadingCore.task.id`；保留多音选择、轻声、完整拼读 | 80个指定读法 + 12个完整拼读 |
| K国王回家 | 当前单词的 `en:` 键 | 9个英语词 |

逐项覆盖清单在 [coverage.json](coverage.json)。221处朗读映射共同复用101条音频，缺口为0；拼读不会改播一个整字，多音字不会退回系统默认读音。

## 播放与交互

- 保留原来的手动听音按钮，没有新增自动播音。打字页原先自动下一题本身不触发朗读，本轮继续如此。
- 本地文件缺失、解码或播放失败时，明确显示“示范暂不可用”；删除全部原生 TextToSpeech 和浏览器 speechSynthesis 兜底，不再悄悄换声音。
- 换字、答对进入笔顺展示、重开、返回、暂停、退出、开始录音时停止示范；播放器本身也处理后台与页面退出。
- 迟到播放结果受会话编号保护，不能覆盖打字的✓、错误反馈或新题文字，也不会修改分数和其他游戏存档。
- 前台恢复只重新允许用户点击，不会自动重播；处于后台的程序调用也不会开始播放。
- 朗读示范与游戏音效开关维持原有独立语义：关游戏音效之后，明确点击听音按钮仍可听到示范。
- 未修改WebView媒体自动播放设置。Android官方文档说明媒体播放可要求用户手势；现所有入口都由用户明确点击播放，故无需放宽该设置。[WebSettings官方文档](https://developer.android.com/reference/android/webkit/WebSettings#setMediaPlaybackRequiresUserGesture(boolean))
