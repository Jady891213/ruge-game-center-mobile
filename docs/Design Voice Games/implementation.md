# 两款声音小游戏：设计与实现

## 儿童玩法

- 怪兽变声冒险：18关，慢速横版过坑、跳过石头、蹲过树枝；用正常音量“啊”或哼声相对本人的高低音控制；提供大号跳/蹲触摸辅助。1～6关学习单动作与组合，7～12关组合变化，13～18关四五个障碍连续挑战。摔落回最近安全检查点，不清整关。障碍前150单位显示提示；正确动作先预约并显示绿色勾，到安全窗口自动执行一次跳，蹲保持到整根树枝通过。坑沿有18px土狼时间，岩石/树枝前沿有0.24秒纠错窗；暂停/后台清掉未执行预约。声音模式中只发数字震动，避免游戏音效被麦克风当作高低音，触摸模式保留音效。
- 口令小冒险：18关，移动到目标、拿起来、送到门/朋友/星星窝再放下。每次方向口令走一格，面对水道时说“跳一下”跨过一格水；不能穿墙。每关需要5～14个动作，允许不同路线，不计时、不惩罚正常试错。
- 场景用图形和物品→目标表示任务，保留短动作词。存档各自独立，不改旧游戏存档。恢复前台保持暂停，继续需要明确操作。

## 共用音频链路

`MainActivity → GameAudio → AudioRecord 16kHz/mono/PCM16 → VoicePitch 或 VoiceRecognizer → RugeAudioNative.read → shared/audio-input.js → 当前游戏`。

GameAudio是全应用唯一音频捕获器；用户按用声音/口令玩才请求麦克风；启动先进入warming，真实PCM完成3次DSP（约224ms）后才宣布listening。新会话清空frames/updated/旧command内容，commandSerial保持单调，所有结果发布检查会话token和前台状态；后台/离页/关闭立即停麦，回到前台不自动重启。采集音频只在内存，未落盘、未联网、未输出原始音频日志。网页辅助按钮明确叫“用手指玩”，不把按钮触发冒充语音识别。

- 音高：本地YIN，75～900Hz、置信度门限、低音量拒绝；收集14个有效采样用中位数标定本人音高。相对基准>1.23高音跳、<0.82低音蹲；持续高音不自动连跳，稳定低音/中音后可再次高音跳。
- 口令：sherpa-onnx v1.13.8固定中文关键词识别，WenetSpeech 3.3M mobile int8 encoder/joiner+fp32 decoder，模型约4.73MB；CPU两线程，约32ms采集块，模型分块和实际端到端延迟需真机测。
- 词表：向左、向右、向上/前进、向下/后退、停下/停一下/停止/停下来、跳一下/跳、拿起来/拿起、放下。不是自由句子理解；不会理解“不要跳”的否定或任意任务。建议逐条清楚说，指令间稍停顿。
- 新增停类词用官方固定源码 `scripts/text2token.py --tokens-type ppinyin` 转换；“停一下”额外保留一的自然变调yí别名。未对全部词再次降低门限；“停住”在合成音检查中不稳定，未收入正式词表。

## 已有证据

- `tests/voice-games.test.mjs`：真实core解18关口令题、真实物理零碰撞跑18关、暂停/继续、下一关回放、坏存档、草稿恢复、封面不写存档、音高相对校准及高低直接交替触发。
- `tests/native-voice.test.mjs`：JDK实际编译并运行真实VoicePitch.java；90/120/240/420/650/800Hz、静音、微弱音量和随机噪声。
- `browser-layout.json`与六张PNG：320×568、392×872、872×392真实Chrome渲染；按钮均在屏内，未出现页面异常。绘制视口随容器匹配，避免竖屏裁掉左边角色。
- `kws-synthetic-result.json`：Mac婷婷合成的8条口令（逐条间隔1秒）均被同版本官方KWS识别；19.5秒不相关普通话、12秒静音/440Hz音调未触发。不是儿童准确率或手机延迟基准。
- MIX4原生麦克风/口令最终验收由主操作者统一完成，证据另放 `docs/Review Playful Games 4.23/`；以该报告为准。

## 美术与边界

原创怪兽四姿态由内置GPT Image生成，随后用内置图片编辑工具去除底色得到真实透明图集。素材在 `app/assets/shared/voice-art/monster-atlas.png`；提示词/输出路径/哈希见 `art-prompts.json`。两款游戏实际角色与封面使用同一素材；地图、道具和按钮图标为本地SVG/Canvas几何，没有远程字体/图片或CDN。

中文儿童发音、方言、远距离、多人背景说话仍需孩子试玩校验；不凭合成音结果保证精度。普通浏览器没有原生中文KWS时保留手指玩法；本机WebAudio仅作为音高游戏的浏览器辅助，Android实际走共享原生麦克风。

## 最终设备复测的准确性边界

最小KWS JNI已在MIX4实际运行，TTS经手机扬声器→真实麦克风→KWS→网页曾分别触发全部8类口令，但单次序列有漏检：初轮5/8，追加复测中“向右”“跳一下”“停止”等有成功，“跳一下”重复时也有失败，“停下/停一下/停下来”不稳定。逐次结果见 `docs/Review Playful Games 4.23/device-final-smoke.json` 与 `device-kws-repeat.json`，不能据此承诺儿童语音准确率。

冷启动记录出现过status=listening而frames=0、ageMs=999999。此次仅修正就绪宣布时机并防旧线程回写；该修正不等于已经证明识别准确率提高。孩子看到的停止口令统一为“停止”；保持已有词表和门限，不在缺乏受控证据时删除裸“跳”或放宽门限。使用时允许清楚逐条重说，也始终提供明确的手指按钮，漏听不扣分、不计时、不丢进度。
