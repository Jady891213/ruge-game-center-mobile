# 钢珠迷宫：转转机关

## 玩法与入口

原来的12关保留全部几何和收集位置，追加第13—18关“转转机关”。选关分两个章节；第13关直接可玩，机关章节自身依次解锁，不自动解锁旧迷宫关。

黄色旋转图标进入调整状态，钢珠立即停下，暂停遮罩退去；直接点画布上的大转轴按钮调整挡板。底部“开始/继续”是明确的恢复动作。调整状态可规划，不运行物理。每关顶部均有重置入口，简短确认后只重置当前关，保留完成与解锁。

## 真实机关

挡板以同一房格左上角为端点，90°切换：竖放挡左入口，横放挡上出口。`rotorWall()`同时提供绘制和碰撞矩形。转动前检查整个保守扫掠圆盘（挡板长度+厚度+球半径+余量）；球在区内时拒绝转动，保留球与朝向，用短震和“先把球移开”提醒。物理冻结期间瞬间完成转向，不播放假转动再突然替换碰撞。

第13/14关学习单个挡板，第15/16关组合两个；第17/18关必须途中换路。先转横从左入口进入，滚到右侧安全口袋收星，再转竖打开上出口。17关同一块至少转两次；18关两块各至少转两次。穷举固定朝向全部无解，不能全开一路过。

## 存档兼容

继续使用`rugeMarbleMazeV1/schema1`，新字段`mechanismReached`默认12（索引）；原`reached`保留经典关卡进度。草稿新字段`rotors`为0/1数组；旧存档缺失时使用当前关初始状态。原12关的`rotors`为空数组。保存保留当前球坐标、已收集星星、钥匙和检查点；恢复时清速度，不还原惯性。不会清理旧`rollingGardenV2`或其他游戏键。
