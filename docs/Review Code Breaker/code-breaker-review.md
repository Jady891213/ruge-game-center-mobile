# 小小密码箱开发与验收

日期：2026-10-11。游戏中心正式版 **4.3 / versionCode 26**，已覆盖安装到小米 MIX 4，保留原应用数据。

## 玩法与教学

采用经典猜数字规则：数字不重复、首位不能为 0。对位表示数字和位置都正确；换位表示数字存在但位置不同；不在表示密码没有该数字。三个数量独立统计，合计等于密码位数。普通猜测只显示数量，输入数字不按答案逐位染色。

| 阶段 | 内容 |
|---|---|
| 明牌教学 | 以密码 24 演示猜 21、42、24；明确说明这里展示答案只为了讲解 |
| 两位入门 01—06 | 先排除、交换位置、保留正确位置、分组排除、认识 0，再做小挑战 |
| 三位进阶 07—12 | 缩小数字范围、调整顺序、含 0 密码，逐步减少起始线索 |
| 四位挑战 13—18 | 综合推理，最后两关从完整数字范围自主猜测 |
| 自由模式 | 每局随机，任选 2/3/4 位；不限次数，或分别限制 6/8/10 次 |

固定关卡共 18 个，顺序解锁，练习不限次数。起始线索不占尝试次数。三星目标与推理提示提供可选的进阶目标，不阻止孩子继续尝试。提示只基于当前线索与候选密码推导。重复猜测、缺位、重复数字和首位 0 不扣次数；挑战最后一次猜中仍判成功。

自动保存草稿、历史、关卡星数及自由模式成绩；返回关卡可继续这一局。切后台后保留状态，回到前台需明确点继续。数据使用独立键 `rugeCodebreakerV1`，恢复时验证输入与终局边界。

## 界面

参考 [SpinFlow 的 Bulls and Cows](https://spinflow.online/) 的历史反馈、数字键盘与计数表达，并核对 [开发者的玩法说明](https://hakanozger.com/guides/bulls-and-cows/)。本项目使用自行实现的奶油色、薄荷绿密码箱界面与中文教学，不引入对方图片或脚本。

数字输入使用页面自带键盘，避免系统输入法遮挡。猜测记录可滚动，键盘与提交按钮保留在下方；对位/换位/不在同时用图标、文字和颜色表达。合集入口封面从实际游戏页面生成，避免封面和玩法不一致。所有资源离线打包。

## 验证结果

- `npm test`：**55/55 通过**，包含 11 项密码规则测试、10 项实际 UI 脚本测试，以及原七个游戏的回归测试。
- 浏览器：390×844 与 320×568；四位布局无横向溢出，小屏提交按钮底边 555px，小于 568px 视口。
- MIX 4 WebView：392×872 CSS px；四位键盘按钮约 53.6×45px，提交底边约 859.7px，无横向溢出。
- 真机教学三步正常；第一关猜 42 得到 0 对位、2 换位、0 不在，猜 24 通关并解锁第二关；四位随机挑战显示 10 次限制。
- 真机普通切后台后密码和状态保留、回来保持暂停、点击继续恢复输入；Android 左侧滑从游戏回合集。
- 测试结束恢复本游戏原存档，新游戏正式交付页面为 0/18，未清除其他游戏数据。
- 正式版启动成功，前台窗口含 `KEEP_SCREEN_ON`；关闭 WebView 调试入口；当前应用进程的 crash 日志为空。
- APK 签名、ZIP 对齐、包名/版本与打包 assets 校验通过。设备已安装 APK 的 SHA-256 与本地正式产物一致。
