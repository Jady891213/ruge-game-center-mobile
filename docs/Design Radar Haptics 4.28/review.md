# 口袋探宝震感 · 4.28

## 调整

问题来自当前页把拨动刻度和接近信号混成同一节奏：转动可用9ms短脉冲抢掉更长的接近提示；周期脉冲又重置了拨动锚点，慢转不容易获得独立刻度。通关的成功效果也可能被下一帧新目标信号覆盖。

现在由`pocket-radar/haptics.js`统一调度：

- 保险箱拨动六度产生刻度，远处的移动刻度至少105/255、16ms；慢转锚点不被周期信号重置，小幅抖动不伪造刻度，359/0按短角差处理。
- 靠近信号按角度距离分七档。转动经过目标就增强，不等hold开始才增强；中心与可通关边缘分开，中心最密最强。
- 强接近信号优先；同次拨动也携带当前远近强弱，不用弱刻度覆盖中心信号。相邻输出至少110ms，继续共用RugeFX和原生8～35ms/90ms限制，不建立积压队列。
- 成功效果保留450ms，再开始下一目标探测；暂停、后台、离开、长帧或无效姿态停止，恢复不补发旧刻度。
- 空间寻宝使用核心的方向＋俯仰球面夹角。历史关卡/双人入口继续沿用原实现，两新模式三秒停稳、加时、最高记录不变。

|距离档|基准节奏间隔|强度0～255|单次时长|
|---|---:|---:|---:|
|背向/很远，超过115°|1050ms|65|13ms|
|75～115°|700ms|100|17ms|
|45～75°左右|480ms|145|21ms|
|较近|340ms|180|24ms|
|通关边缘外12°内|230ms|210|28ms|
|有效区域内|165ms|235|32ms|
|中心，最多5°|120ms|255|35ms|

精确边界取实际关卡tolerance，详见`profile()`；上表“较近”与45°附近由动态门限计算。这里的频率是短脉冲的节奏，并未调节马达载波频率。无幅度控制的设备仍可用时长/节奏区分，但本轮真机是支持幅度控制的MIX4。
