# 口令小冒险 UI 与动作重制（4.24）

## 本次调整

- 保留 `core.js` 的 18 关地图、有限口令与原存档键。钥匙开门、苹果喂兔、星星回巢三种任务用不同的交付动画与结算；草稿中的朝向、持物、位置、已解锁与星数延续。
- 进入关卡默认准备声音；下一关复用仍在运行的关键词会话，不再每关询问“声音/手指”。首次权限或不可用时有重试与手指辅助，辅助方向盘默认折叠。
- 地图分为固定地形、目标、物品、人物、手持物、粒子层。人物节点持续存在；移动不再销毁重画整个地图。树墙和角色使用 GPT 生成图片，角色在墙与物品上层。
- 普通行走 300ms（真实 4 帧走路循环）；跨水 520ms、原地跳 460ms（起跳/落地帧与高度变化）；拿起 440ms；交付 850ms，包含开门/兔子开心/鸟巢发光、彩纸和开心帧。所有持续时间由实际动画状态管理。
- 角色在移动过程中只缓冲最新一条识别口令，避免同时瞬移多个格；“停止”清掉下一条。原网页用额外的毫秒去抖会吞掉已更新 serial 的有效下一词，现由原生 serial 去重与一条动画缓冲共同处理。
- 当前任务只有三个图标步骤；拾物处、交付处给简短“拿起/放下”，不增加常驻说明段落。麦克风、输入能量条与听到的口令在底部可见。
- 声控期间通过共享触觉反馈确认动作，不播放应用扬声器音效，防止自身声音被当成口令。手指模式沿用声音与震动偏好。
- 暂停/后台/导航关闭麦克风；回前台不自动行动，明确继续才恢复。中途暂停把视觉人物收敛到已完成的真实格子并清掉缓冲，不在后台补走。

## 生产美术来源

- 总体三联原型：`visual-prototype.png`，原始生成提示词在 `art-prompts-root.json`。
- `shared/playful-art/forest-world.png` 为本轮新生成浅净中央森林背景；没有把示意图中的固定路线/房子烘焙进碰撞地图。
- `shared/playful-art/forest-props.png` 为本轮 imagegen 编辑后的真实透明六格道具图集；不是 CSS/Emoji 角色替代。空白与格子接缝九个样本 alpha 为 0。底层 RGB 仍含原色不影响透明合成，未做程序化抠图。
- `shared/playful-art/hero-frames.png` 由根任务生成；真实 alpha 主体裁图按共同像素比例与脚底定位，消除奔跑脚底跳动与最后一行跨格残片。行走、跨水、开心用相应生成姿态，不靠单张形变冒充逐帧。
- 树墙使用本轮 `shared/playful-art/tree.png`；地图边/门/水坑与真实核心规则一一对应，角色持续置顶。
- 本轮生成/编辑原始提示词、输出源文件名、SHA-256、尺寸及 alpha 样本见 `quest-art-prompts.json`。

## 真机交接

- 此专项没有操作手机。根任务负责实际 Android 关键词链路、安装、旧存档完整备份恢复与系统返回复测。
- 默认语音入口 `__game.openLevel(0,false)`；首次 idle 自动 `RugeAudioInput.start('command')`；后续仍 listening 同模式则不重复 start/stop。
- `__game.animation` 为当前真实持续动作，`__game.visual` 为格子间的可视坐标，`__game.queued` 为最多一条声音缓冲。设备自动验收应等待 animation 为空，再进入下一次触摸动作；不要瞬间求解循环跳过动画。
- 辅助按钮默认隐藏，点 `#padToggle` 展开；真实麦克风命令经同一个 `command(name,'voice')` 和 core.act 执行。
- 终局有 850ms 交付动画后显示 `#win`；下一关默认语音，读入当前 commandSerial，忽略终局期间产生的旧识别结果。
- 专项浏览器/context 已 finally 关闭，临时验证脚本已清理；没有启动或遗留 HTTP 服务。
