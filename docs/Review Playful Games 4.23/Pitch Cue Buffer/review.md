# 怪兽变声冒险：提示与动作预约

## 修复

旧版在障碍前170单位显示“跳/蹲”，孩子照提示立刻操作会提前落地或提前结束蹲姿。新规则在前150单位预告，正确动作收到后立即显示绿底“✓ 跳/蹲”，预约绑定这一处障碍；走到安全区再执行。蹲姿保持至整根树枝通过，不要求持续喊到结束。

未执行预约在暂停、离开页面时清掉；恢复不会执行旧口令。坑边18px可晚起跳，岩石/树枝前沿有0.24秒小缓冲；仍须给出正确动作，单次预约不能自动处理后续障碍。远离障碍时手指起跳立即执行。

声音模式运行时动作、收集和错误只调用数字 `RugeFX.pulse`，保留触觉与视觉反馈，避免扬声器音调被麦克风当作新输入。开始声音模式前停止残余音效；通关先停麦克风，再播放胜利反馈。触摸模式正常播放音效，不修改全局声音偏好。

## 验证

- 新增 `tests/pitch-cues.test.mjs` 11项，连同声音原有13项共24项通过。
- 18关按提示第一帧只发一次正确动作，真实物理全部零碰撞通关。
- 分别模拟从提示起延迟1.2秒、1.45秒再发动作，18关均可通。这是游戏容错窗口测试，不是手机ASR延迟基准。
- 验证连续输入不重复起跳、蹲姿只覆盖当前树枝、晚输入、后台清理预约、存档检查点、18关真实VM页面连续下一关和三星保存。
- 验证声音模式只发数字触觉脉冲，麦克风停后才 `emit('win')`，触摸模式保留普通音效。
- Chrome 320×568实际操作第1/4/18关：在提示出现后立刻点击对应按钮，显示收到确认，并按正常帧率物理完成，三关都零碰撞、收齐星星；未注入胜利或加速时间。详情见 [browser-cues.json](browser-cues.json)，同目录保留预约与胜利截图。

浏览器独占会话及临时HTTP服务器已在 `finally` 关闭。未操作手机，真实儿童音域、关键词识别准确率、设备震动与手机回录仍由主集成验收。
